# AGENTS.md

## Cursor Cloud specific instructions

MaxXP is a single-page portfolio app (Vite + React 19 + TypeScript) themed as a Windows XP desktop. There is no backend service — it is a static client app. See `PRODUCT.md` for product context and `package.json` for the full script list.

### Services / commands

- Dev server: `npm run dev` (Vite, binds `0.0.0.0:5173`). This is the primary way to run the app while developing.
- Build (also the only type-check gate): `npm run build` refreshes anonymous public GitHub metadata, checks curated deployment links, then runs `tsc -b && vite build`. The refresh needs network access and fails the build rather than publishing an unverified catalogue. There is **no ESLint config**. `node --test scripts/github-projects.test.mjs scripts/live-apps.test.mjs` checks the public-data boundary and deployment fallbacks.
- Preview a production build: `npm run preview` (binds `0.0.0.0`).

### Non-obvious notes

- Dependencies install with **npm** (`package-lock.json`). `.npmrc` maps the `@jsr` scope to `https://npm.jsr.io` — this is required for the `@etareduction/humantypingts` dependency to resolve, so don't remove it.
- Vite dev-server proxies `/cm/*` to `https://commits.sh/api/*` (see `vite.config.ts`); `vercel.json` does the same rewrite in production. The "Dev Stats" window and other live panels fetch real GitHub / commits.sh data at runtime. The desktop boots and is fully interactive **without** network access — only the live-telemetry panels degrade when outbound network is unavailable.
- Clicking a project inside the "My Projects" explorer opens the real GitHub repo in a new browser tab; that is expected behavior, not a crash.
- `src/radio/` is the KK6OQA radio (SDR console + TS-2000 view). It opens with a signature window at login and greets in Morse on its own: with sound when the browser allows it, otherwise keyed silently with the tone joining at the first tap, click or key anywhere (STOP holds it; SEND resends). `band.ts` models the band row by row (noise grain, other CW stations, static, our carrier) and `Spectrum.tsx` draws the panadapter + waterfall on one canvas. The screens are pure functions of time so the intro film renders them too; keep them free of site-only imports.
- Optional maintenance scripts are not needed to run the app: `npm run projects:refresh` (anonymous public GitHub API only; never pass a token, see `scripts/fetch-github-projects.mjs`), `npm run reels:cut` (re-cuts Demo Reel clips from the raw screen recordings; requires `ffmpeg` and the recordings), and `npm run resume:build` (requires a LaTeX `pdflatex` toolchain).
- The intro film is a separate Remotion project in `intro-film/` (own `package.json`; run `npm run intro:setup` once). `npm run intro:build` cuts the reviewed recording crops, renders both orientations, and publishes content-hashed MP4s to `public/videos/intro/`, updating `src/xp/IntroVideo.tsx`. It needs the original recordings, `ffmpeg`, and a few GB of free disk. `npm run intro:clean` removes only reproducible intermediates (cut clips, Remotion temp bundles); original recordings, render masters, and published videos are never removed. The intro MP4s are not in git: they live on the `intro-films` GitHub release, `npm run build` fetches the files listed in `intro-film/published.json` and fails on a hash mismatch, and after `intro:build` you must run `npm run intro:upload` before pushing. Other large demos (the Orbital Works film in My Projects) work the same way through `scripts/release-media.json` and `npm run media:upload`; never commit MP4s. The soundtrack (`intro-film/music.py`) needs GarageBand's Apple Loops installed; `intro-film/score.json` is the shared beat grid. The quill's calligraphy (the intro's opening and the site's quill window) shares one stroke model, `src/lib/signatureStrokes.json`, drawn by `src/lib/calligraphy.ts`. It is built from the traced signature by `scripts/signature/` (`graph.py` → centre-line graph, `route.json` → hand-routed writing order, `build.py` → smoothed, timed strokes; `zoom.py` draws numbered edge sheets for re-routing). Rebuild with `python3 scripts/signature/graph.py && python3 scripts/signature/build.py`.
- `.github/workflows/refresh-public-projects.yml` refreshes public GitHub data and deployment checks every six hours. GitHub archive metadata remains exact; the live app showcase is an editorial selection. Keep Cash Clicker out of the showcase.
